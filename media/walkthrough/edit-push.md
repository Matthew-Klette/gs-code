# Edit, review, push

- Search and replace across the folder (`⇧⌘F` / `Ctrl+Shift+F`), multi-cursor, or ask your AI agent.
- The **GS Code** section in Source Control lists every change; click one for a diff against GTM.
- Problems (unknown triggers, missing variables, duplicate names) block the push until fixed.
- **Push** shows the list and asks first. It writes to the workspace, never to the live site.
- **Create Version and Publish** is a separate step that asks you to type the container id.
