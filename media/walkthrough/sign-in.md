# Sign in

Pick the JSON you downloaded, then sign in in the browser. Google shows "Google hasn't verified this app" because the app is yours; choose **Continue**.

- Want a sign-in that can never publish? Set `gsCode.allowPublish` to `false` first.
- Working over Remote-SSH, WSL, a container or Codespaces? If the browser ends on a "can't connect" page, paste its address into the box GS Code shows.
