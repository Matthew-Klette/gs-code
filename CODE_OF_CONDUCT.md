# Code of Conduct

GS Code follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in issues, pull requests, discussions and reviews is expected to follow it.

In short: be respectful and considerate, assume good intent, accept feedback on your work gracefully, and do not harass anyone. Harassment, personal attacks and publishing someone else's private information are not acceptable.

## Reporting

To report behaviour that breaks the code of conduct, contact the maintainer through GitHub, [@Matthew-Klette](https://github.com/Matthew-Klette). If it should not be public, ask for a private channel first rather than describing it in an issue. Reports are handled in confidence, and the maintainer will act as described in the Contributor Covenant's enforcement guidelines.
